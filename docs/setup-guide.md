# Setup Guide - SkyOps-RAP-BTP

## Prerequisites
- SAP BTP Trial Account
- Eclipse IDE with ADT plugin
- ABAP Environment instance

## Steps
1. Create DB table ZFLIGHTBOOKING in ADT
2. Create Interface CDS View ZI_FlightBooking
3. Create Consumption View ZC_FlightBooking
4. Create Behavior Definition and Implementation
5. Create Service Definition and Binding
6. Publish and Preview in Fiori Elements
